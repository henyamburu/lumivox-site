# Lumivox Page Expectations

_Last updated: 2026-05-30_

This file defines what each key Lumivox page should accomplish.

## Homepage

### Purpose

The homepage should quickly explain what Lumivox is, why it matters, and where the reader should go next.

### Required Elements

- Clear hero headline.
- Short subheadline explaining the smart sleep/smart living concept.
- Problem section: sleep data often does nothing by itself.
- Lumivox Loop: Input → System → Output.
- Simple explanation of the beginner setup.
- CTA to Sleep System or Start Here.
- Optional video section if available.
- Trust/limitation language.

### Avoid

- Too many product links on the homepage.
- Overclaiming sleep improvement.
- Making the page feel like a generic gadget landing page.

## Sleep System Page

### Purpose

The Sleep System page should explain the practical starter setup and guide readers toward product options or a checklist.

### Required Elements

- Explanation of the system.
- Product stack: sleep tracker, smart bulbs, smart plug.
- Setup flow.
- Product cards or table.
- Affiliate disclosure if product links appear.
- CTA tracking.
- Link to checklist or setup article.

### Product Stack

| Category | Options |
|---|---|
| Sleep tracker | Fitbit Inspire 3 or Xiaomi Smart Band. |
| Smart bulbs | Govee Smart Bulbs or Wyze Bulbs. |
| Smart plug | Kasa Smart Plug or TP-Link EP25. |

### Avoid

- Unsupported current pricing claims.
- Claims that products cure sleep problems.
- Broken or untracked product CTAs.

## About Page

### Purpose

The About page should build trust and clarify the Lumivox philosophy.

### Required Elements

- Who Lumivox helps.
- What Lumivox is not.
- Why the site focuses on practical systems.
- Clear non-medical positioning.
- CTA to Start Here or Sleep System.

### Avoid

- Corporate-sounding fluff.
- Overly broad claims.
- Hiding limitations.

## Start Here Page

### Purpose

The Start Here page should guide a new reader into the simplest possible path.

### Recommended Elements

- Step 1: Understand your current routine.
- Step 2: Choose one input source such as a wearable.
- Step 3: Choose one environmental adjustment such as lighting.
- Step 4: Add one automation such as a smart plug.
- Step 5: Track what changes over 1–2 weeks.
- CTA to beginner checklist.

## Products Page

### Purpose

The Products page should organize product recommendations without becoming thin affiliate content.

### Required Elements

- Category-based organization.
- Practical reason each product fits.
- Pros and cons.
- Who should choose each option.
- Affiliate disclosure.
- `/go/` tracked product CTAs.

## Article Pages

### Purpose

Article pages should answer specific reader questions and link back to the Lumivox system.

### Required Elements

- Clear H1.
- Useful intro.
- Quick answer or summary.
- Practical sections.
- Internal links.
- CTA.
- Disclosure if product links appear.
- SEO metadata if supported.

## Product Comparison Pages

### Purpose

Comparison articles should help readers choose, not simply push one product.

### Required Elements

- Quick recommendation by use case.
- Comparison table.
- Pros/cons for each product.
- Best fit scenarios.
- Limitations.
- CTA through tracked links.

### Example Recommendation Pattern

```text
Choose [Product A] if you want [reason].
Choose [Product B] if you want [reason].
For most beginners building a Lumivox-style setup, the better choice depends on [factor].
```

## Redirect Pages under `/go/`

### Purpose

Redirect pages should support measurable product-click intent.

### Required Elements

- Correct destination.
- No 403/404.
- Consistent tracking behavior.
- Minimal user friction.

### Avoid

- Random product destinations.
- Unclear link changes.
- Hardcoded affiliate IDs not provided by the user.

## Footer

### Purpose

The footer should support navigation, disclosure, and trust.

### Recommended Links

- Home.
- Sleep System.
- About.
- Start Here or Articles if present.
- Affiliate disclosure if separate.
- Contact if present.

## Definition of Done for Page Work

- [ ] Page purpose is clear.
- [ ] CTA is clear.
- [ ] Internal links are correct.
- [ ] Tracking is preserved.
- [ ] Affiliate disclosure appears where needed.
- [ ] Mobile layout works.
- [ ] Page passes testing checklist.
- [ ] Docs updated if structure changed.

# Lumivox SEO Checklist

_Last updated: 2026-05-30_

This checklist helps keep Lumivox content useful, searchable, and trustworthy.

## SEO Philosophy

Lumivox should avoid low-quality affiliate SEO. The best content should answer real beginner questions and naturally connect to the Lumivox sleep-system concept.

## Page-Level SEO Checklist

For every page or article:

- [ ] One clear H1.
- [ ] Unique page title.
- [ ] Useful meta description if the site supports meta tags.
- [ ] Logical H2/H3 structure.
- [ ] Descriptive URL slug.
- [ ] Internal links to related Lumivox pages.
- [ ] External links only when useful and trustworthy.
- [ ] Images have alt text.
- [ ] Product claims are accurate and current if specific.
- [ ] No keyword stuffing.
- [ ] No medical overclaiming.

## Suggested URL Slug Pattern

Use short, readable slugs.

Examples:

```text
/articles/starter-sleep-automation-under-250/
/articles/fitbit-inspire-3-vs-xiaomi-smart-band-sleep-tracking/
/articles/govee-vs-wyze-smart-bulbs-evening-routines/
/articles/kasa-smart-plug-sleep-routine-setup/
/articles/bedroom-wind-down-automation/
/articles/wearable-sleep-data-limitations/
/articles/beginner-smart-home-sleep-system-checklist/
/articles/who-lumivox-is-for/
```

If the repository already uses a different article URL structure, follow the existing structure.

## Title Guidance

Good titles are specific and practical.

Examples:

- Best Starter Sleep Automation Setup Under $250
- Fitbit Inspire 3 vs Xiaomi Smart Band for Sleep Tracking
- Govee Smart Bulbs vs Wyze Bulb Color for Evening Routines
- Kasa Smart Plug Setup for Sleep Routines
- How to Build a Bedroom Wind-Down Automation

Avoid vague titles:

- Better Sleep With Tech
- Smart Home Tips
- Best Devices for Everyone

## Meta Description Guidance

A good meta description should:

- State the problem.
- Mention the practical outcome.
- Avoid hype.
- Stay concise.

Example:

```text
Build a beginner smart sleep setup with a wearable, smart bulbs, and a smart plug. See what to buy, how it works, and what to avoid.
```

| Trust article | About, Start Here, Sleep System. |
| Checklist | Sleep System, product stack, guide articles. |

## E-E-A-T / Trust Signals

Lumivox should demonstrate trust through:

- Practical testing mindset.
- Clear limitations.
- Transparent affiliate disclosure.
- Honest product tradeoffs.
- Avoidance of medical claims.
- Clear explanation of who the setup is and is not for.

## FAQ Guidance

Add FAQ sections when they help the reader, not just for SEO.

Possible FAQ topics:

- Do I need a smartwatch for Lumivox?
- Can smart bulbs really improve sleep?
- Does Lumivox diagnose sleep problems?
- What is the cheapest way to start?
- Can I use only a smart plug?
- What if I rent and cannot change wiring?

## Product SEO Caution

Before publishing product-specific content, verify:

- Product name.
- Current model/version.
- Current compatibility.
- Pricing range if mentioned.
- App ecosystem.
- Whether the product is still widely available.

Do not rely on old product specs without checking.

## Definition of Done

- [ ] Title and meta description are clear.
- [ ] Page has useful structure.
- [ ] Intent is answered early.
- [ ] Internal links are present.
- [ ] Affiliate disclosure is present if product links are included.
- [ ] Content is helpful beyond product promotion.
- [ ] No medical overclaims.
- [ ] No unsupported product claims.

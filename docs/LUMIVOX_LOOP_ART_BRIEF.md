# Lumivox Loop Art Improvement Brief

## Purpose

Improve the current “Lumivox Loop” visual so it communicates a meaningful feedback loop, not just a simple left-to-right process.

The visual should explain the core Lumivox idea:

> Wearable data informs the system.
> The system adjusts the bedroom environment.
> The results are measured.
> The next night improves based on the feedback.

This should feel like a calm, intelligent sleep environment — not a generic smart home diagram.

---

## Current Issue

The existing visual shows:

Wearable → System → Results

This is clean and simple, but it feels too linear. It does not fully communicate that Lumivox is a repeated cycle where results feed back into the next routine.

The current house icon is useful, but the surrounding visual should make the home feel like the center of a responsive sleep system.

---

## Recommended Concept

### Concept Name

**The Lumivox Sleep Feedback Loop**

### Visual Structure

Place the home/bedroom icon at the center.

Around it, create a soft circular or orbital loop with four connected steps:

1. **Sense**
   - Wearable captures sleep, movement, heart rate, routine behavior, or rest data.

2. **Interpret**
   - Lumivox system reads the pattern and decides what should happen.

3. **Adjust**
   - Smart lights, plugs, temperature, or wind-down cues respond.

4. **Improve**
   - The next sleep result becomes feedback for the next evening routine.

The loop should visually return back to “Sense” to show continuous learning.

- Wearable Data

- Bedroom Response
- Better Sleep Signals

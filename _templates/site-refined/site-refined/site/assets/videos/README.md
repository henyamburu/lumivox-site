# Video upload folder

Upload your prepared MP4 videos here using these filenames:

1. `lumivox-overview.mp4`
   - Used on the Home page after the Problem section.

2. `sleep-system-demo.mp4`
   - Used on the Sleep System page after the Input → System → Output framework.

Recommended:
- MP4 format
- 1080p or 720p
- Keep each file as small as practical. For GitHub Pages, avoid very large files.
- If the video files become large, host them on YouTube/Vimeo later and replace the `<video>` block with an `<iframe>` embed.
